📖 Paano kumuha at maglagay ng Gemini API Key? (Step-by-Step Guide) ▼
  1. Buksan ang Google AI Studio sa link na ito: https://aistudio.google.com/apikey ↗
  2. Mag-sign in gamit ang iyong Google / Gmail account.
  3. I-click ang button na "Create API key" (o "Get API key"). Kung hihingin na pumili ng project, i-click lang ang "Create API key in new project" o pumili ng existing project.
  4. Kapag lumabas na ang key (karaniwang nagsisimula sa AIza...), i-click ang Copy.
  5. Bumalik dito sa Study Master, i-paste ang key sa Gemini API Key box sa itaas, tapos i-click ang Test Key at Save Settings.
Paalala sa Seguridad: Huwag i-share ang iyong API key sa ibang tao o i-post online. Libre ang Google AI Studio free tier para sa personal na pag-aaral, pero may limit kada minuto — kaya may built-in Auto-Fallback ang app na ito!
